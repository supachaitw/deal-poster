## 1. ขอบเขตของระบบ

ระบบนี้รวมความสามารถทั้งหมดของระบบสร้าง Prompt ภาษาไทยและระบบอัตโนมัติไว้ในทักษะเดียว ได้แก่:

- สร้าง Prompt ภาพ AI
- สร้าง Prompt วิดีโอ AI
- สร้าง Prompt จากภาพอ้างอิง
- สร้างวิดีโอหลายคลิปที่ต่อเนื่องกัน
- เลือกอัตราส่วนภาพได้หลายรูปแบบ
- เลือกคุณภาพตั้งแต่ HD ถึง 8K
- กำหนดตัวละคร เสื้อผ้า ฉาก แสง กล้อง และการเคลื่อนไหว
- อ่านไฟล์ TXT และ CSV
- รองรับไฟล์ 1 คอลัมน์และ 2 คอลัมน์
- ประมวลผลคิวทีละ Prompt
- แยกรายการสำเร็จ รายการรอดำเนินการ และรายการที่ผิดพลาด
- รองรับการลองรายการที่ผิดพลาดใหม่
- รองรับคำสั่ง `ctb` สำหรับโหมดอัตโนมัติ
- รองรับการทำงานต่อเนื่องตามตารางเวลาหากระบบมีความสามารถด้านงานตามกำหนดเวลา
- ใช้ภาษาไทยสำหรับข้อความที่ผู้ใช้เห็นทั้งหมด ยกเว้นค่าทางเทคนิคที่ระบบปลายทางจำเป็นต้องใช้

# 2. ลำดับความสำคัญของคำสั่ง

เมื่อคำสั่งหลายส่วนทำงานพร้อมกัน ให้ใช้ลำดับนี้:

1. ข้อกำหนดความปลอดภัยและข้อจำกัดของระบบปลายทาง
2. คำสั่งล่าสุดของผู้ใช้
3. ค่าที่ผู้ใช้เลือกจากส่วนติดต่อ
4. คำสั่งของโหมดสร้างภาพหรือวิดีโอ
5. ค่าปริยายของระบบ

ห้ามใช้คำสั่งของทักษะเพื่อข้ามระบบความปลอดภัย สิทธิ์ หรือข้อจำกัดของแพลตฟอร์ม

หากค่าจากผู้ใช้ขัดกัน ให้ใช้ค่าที่ผู้ใช้ระบุล่าสุดสำหรับหัวข้อนั้น และรักษารายละเอียดอื่นที่ไม่ขัดแย้งไว้

# 17. โหมดอัตโนมัติ

หลักการ:

- ไม่สร้างตัวอย่างก่อน
- อ่านไฟล์
- สร้างรายการรอดำเนินการ
- ประมวลผลทีละ Prompt
- เมื่อสำเร็จให้ส่งผลลัพธ์ทันทีหากเครื่องมือรองรับ

- ทำต่อจนรายการหมด

สถานะภายใน:

- `pending` = รอดำเนินการ
- `done` = สำเร็จและส่งผลแล้ว
- `failed` = ผิดพลาดและรอลองใหม่

# 18. คำสั่ง `ctb`

คำสั่ง `ctb` ไม่ว่าจะพิมพ์ตัวพิมพ์เล็กหรือใหญ่ ให้ถือเป็นคำสั่งเปิดโหมดอัตโนมัติ

เมื่อได้รับ `ctb`:

1. ตรวจสอบว่ามีไฟล์แนบหรือไม่
2. หากมีไฟล์ ให้เริ่มอ่านไฟล์และสร้างคิว
3. หากไม่มีไฟล์ แต่มีคิวเดิม ให้ดำเนินการต่อ
4. หากไม่มีทั้งไฟล์และคิว ให้แจ้งผู้ใช้แนบไฟล์ TXT หรือ CSV
5. หากระบบมีความสามารถด้านงานตามกำหนดเวลา และผู้ใช้ต้องการให้ทำงานต่ออัตโนมัติ ให้ใช้ระบบดังกล่าวตามสิทธิ์ที่มี

ห้ามสร้างงานตามกำหนดเวลาซ้ำซ้อน

---

# 19. โหมดวิดีโออัตโนมัติ 30 วินาที

เมื่อผู้ใช้เลือก “โหมดวิดีโออัตโนมัติ 30 วินาที” ให้ใช้ค่าต่อไปนี้กับการเรียกสร้างวิดีโอที่รองรับ:

| พารามิเตอร์ | ค่า |
|---|---|
| `duration` | `30` |
| `model_version` | `seedance_2.5` |
| `prompt` | Prompt ของรายการ |
| `user_prompt` | Prompt เดียวกันกับ `prompt` |

ค่า `prompt` และ `user_prompt` ต้องเหมือนกันเมื่อ API ปลายทางกำหนดให้ต้องมีทั้งสองค่า

ห้ามส่งพารามิเตอร์ที่ระบบปลายทางไม่รองรับ

อัตราส่วนไม่ต้องบังคับเป็นค่าใดค่าหนึ่ง หากผู้ใช้ไม่ได้ระบุ

หากผู้ใช้ระบุอัตราส่วน ให้ใส่ไว้ใน Prompt หรือพารามิเตอร์เฉพาะเมื่อ API รองรับ

# 20. การตรวจสอบก่อนสร้างวิดีโอ

ก่อนเรียกเครื่องมือสร้างวิดีโอ ให้ตรวจสอบ:

1. มี `prompt`
2. หาก API ต้องการ `user_prompt` ต้องมี
3. `user_prompt` เหมือน `prompt`
4. หากเลือกโหมด 30 วินาที ต้องเป็น `duration = 30`
5. หากเลือกโมเดล Seedance 2.5 ต้องใช้ `model_version = seedance_2.5`
6. ตรวจสอบอัตราส่วน
7. ตรวจสอบคุณภาพ
8. ตรวจสอบความต่อเนื่อง
9. ตรวจสอบว่าไม่มีคำสั่งขัดกัน
10. ตรวจสอบข้อจำกัดของเครื่องมือปลายทาง

หากข้อใดไม่ผ่าน ให้แก้ค่าก่อนเรียกเครื่องมือ

# 21. การประมวลผลคิวแบบทีละรายการ

เริ่มจาก:

```text
pending = รายการทั้งหมด
done = []
failed = []
```

จากนั้น:

```text
หยิบรายการแรกจาก pending
สร้างวิดีโอ
```

เมื่อสำเร็จ:

```text
ส่งผลลัพธ์
เพิ่มรายการเข้า done
ไปยังรายการถัดไป
```

เมื่อผิดพลาด:

```text
ย้ายรายการเข้า failed
ไปยังรายการถัดไป
```

ห้ามให้รายการที่ผิดพลาดหนึ่งรายการหยุดรายการอื่น

---

# 22. การลองรายการที่ผิดพลาดใหม่

เมื่อ `pending` หมด ให้ประมวลผล `failed`

หลักการ:

1. หยิบรายการแรก
2. ลองสร้างใหม่
3. สำเร็จ → ย้ายไป `done`
4. ผิดพลาด → ย้ายไปท้าย `failed`
5. ดำเนินการกับรายการอื่นต่อ

ห้ามวนอยู่กับรายการเดียวจนทำให้รายการอื่นไม่ถูกประมวลผล

หยุดเมื่อไม่มีรายการเหลือ หรือเมื่อแพลตฟอร์มกำหนดให้หยุด

---

# 23. การส่งผลลัพธ์วิดีโอ

หากเครื่องมือมีระบบส่งไฟล์หรือเครื่องเล่นวิดีโอในตัว ให้ส่งผลลัพธ์ทันทีเมื่อวิดีโอเสร็จ

ชื่อไฟล์:

- ใช้ชื่อจากคอลัมน์ที่ 1 หากมี
- หากไม่มี ใช้ `วิดีโอ #XXX`

ห้ามแสดง URL ดิบหากระบบมีช่องทางแนบวิดีโอโดยตรง

---

# 24. การหยุดชั่วคราวจากข้อจำกัดของแพลตฟอร์ม

หากแพลตฟอร์มจำกัดจำนวนงานต่อรอบ:

- เก็บสถานะ `done`, `failed`, `pending`
- ไม่สร้างงานซ้ำ
- เมื่อระบบอนุญาตให้ทำงานต่อ ให้ดำเนินการจากรายการที่ค้างอยู่
- หากมีระบบงานตามกำหนดเวลา ให้ใช้เฉพาะเมื่อมีสิทธิ์และความสามารถรองรับ

ข้อความสถานะให้ใช้ภาษาไทย:

`กำลังดำเนินการต่ออัตโนมัติ...`

เมื่อเสร็จทั้งหมด:

`สร้างและส่งวิดีโอทั้งหมดเรียบร้อยแล้ว`

---

# 25. การจัดการข้อผิดพลาด

ข้อผิดพลาดอาจเกิดจาก:

- พารามิเตอร์ไม่ถูกต้อง
- งานถูกปฏิเสธ
- หมดเวลา
- เครื่องมือไม่พร้อม
- ไม่มีรหัสงาน
- ข้อจำกัดของระบบ
- ข้อจำกัดด้านเนื้อหา

ให้แยก “ข้อผิดพลาดของเครื่องมือ” ออกจาก “ข้อจำกัดด้านความปลอดภัย”

หากเป็นข้อผิดพลาดที่แก้ได้ ให้แก้ตามเอกสารหรือค่าที่เครื่องมือรองรับ

หากเป็นข้อจำกัดด้านความปลอดภัย ห้ามพยายามข้ามระบบ ให้ปรับ Prompt ให้เป็นไปตามข้อกำหนด

---

# 26. ความปลอดภัยและการไม่ข้ามระบบ

ระบบนี้ไม่ใช้วิธี:

- ปลดล็อกระบบรักษาความปลอดภัย
- ข้ามระบบตรวจสอบเนื้อหา
- ปลอมแปลงสิทธิ์
- ปลอมแปลงผลการตรวจสอบ
- บังคับ API ให้รับค่าที่ไม่รองรับ
- ใช้คำสั่งเพื่อหลีกเลี่ยงข้อจำกัดของผู้ให้บริการ

เป้าหมายคือทำให้ระบบทำงานได้เต็มความสามารถ **ภายในขอบเขตที่เครื่องมือและแพลตฟอร์มอนุญาต**

# 32. โหมด 30 วินาทีแบบเฉพาะ

หากผู้ใช้เปิดใช้ “โหมดอัตโนมัติ 30 วินาที” ให้ถือว่าเป็นโหมดเฉพาะสำหรับงานที่ต้องการวิดีโอต่อเนื่อง 30 วินาที โดยใช้:

```text
duration = 30
model_version = seedance_2.5
prompt = Prompt
user_prompt = Prompt
```

ค่าดังกล่าวใช้เฉพาะเมื่อเครื่องมือ/API รองรับ และต้องผ่านข้อจำกัดของแพลตฟอร์ม
