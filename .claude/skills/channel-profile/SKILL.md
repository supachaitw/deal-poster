# โปรไฟล์ที่ทำให้คน "เชื่อและอยากซื้อ" — 5 ระดับ

ที่มา: Instagram Reel https://www.instagram.com/reel/DbamrmzMRol/ (@its.howardwang, 32 วิ) ถอดด้วย Gemini 4 ต.ค. 69 · ตรวจแล้ว: เป็น best practice ทั่วไปของ personal/brand bio (ชัดเจนว่าช่วยใคร + social proof + CTA) ไม่ใช่ความเห็นเฉพาะตัว · ส่วนที่เป็นโฆษณา = "ทำให้ธุรกิจดีขึ้นใน 1 นาที"

| ระดับ | สิ่งที่ต้องมี | ตัวอย่างในคลิป | ของเรา |
|---|---|---|---|
| อนุบาล | รูปหน้าตรงแบบถ่ายบัตร · ชื่อสั้น · bio ว่าง/ทั่วไป ("Digital creator") | — | ❌ TikTok @sup.tw ชื่อ "Paiyaa deal" ไม่มี bio = ระดับนี้ |
| ประถม | **รูปโปรไฟล์มีบุคลิก** (ยิ้ม/ชี้) + **ช่องชื่อ = ชื่อ \| สิ่งที่ทำ** | "Howard Wang \| ที่ปรึกษาด้านการตลาด" | "ป้ายยาดีลเด็ด \| รวมดีล Shopee Lazada ลดแรง" |
| มหาลัย | **bio บรรทัด 1 = ช่วยใคร + อย่างไร** | "ช่วยธุรกิจเพิ่มยอดขายด้วย SEO, Google Ads และ AI" | "คัดดีลของใช้บ้าน แกดเจ็ต ของกิน ที่ลดจริง ให้คนไม่อยากเสียเวลาหาเอง" |
| มือโปร | **bio บรรทัด 2 = หลักฐาน/ผลงาน/ตัวเลขจริง** | "ผู้ก่อตั้ง SGE Group • ยอดขายกว่า 400 ล้าน" | "ดีลใหม่ทุกวัน 7 รอบ • รวมไว้แล้วกว่า 500 ดีลที่ paiyaadeals.com" (ตัวเลขต้องเช็คจาก Notion ก่อนใช้) |
| สุดยอด | **บรรทัดสุดท้าย = CTA บอกว่าให้ทำอะไร** | "ปรึกษาหรือร่วมงาน คลิกด้านล่าง" | "ดูดีลวันนี้ 👉 paiyaadeals.com" / TikTok: "ดีลเต็ม ๆ อยู่ในเว็บชื่อเดียวกัน" |

หลักย่อยที่คลิปเน้น: ช่องชื่อ (name field) ค้นหาเจอได้ จึงใส่คำที่คนค้น ("ดีล", "Shopee", "ลดราคา") · bio ทุกบรรทัดเขียนจากมุมคนอ่าน ไม่ใช่มุมเรา

## ร่าง bio ต่อแพลตฟอร์ม (เสนอ user ก่อนใช้ — ห้ามแก้โปรไฟล์ผ่าน API เอง)
- **Instagram @paiyaa_deals** (⛔ ถูกจำกัดลิงก์ถึง 26 ต.ค. 69 — ห้ามใส่ลิงก์ในไบโอ/สตอรี่/DM ก่อนวันนั้น · ต้องมี**เปิดเผยพันธมิตร** เป็นหนึ่งในเงื่อนไขแก้ข้อจำกัด)
  ชื่อ: `ป้ายยาดีลเด็ด | ดีล Shopee Lazada ลดแรง`
  บรรทัด 1: `คัดดีลของใช้บ้าน แกดเจ็ต ของกิน ที่ลดจริง ไม่ต้องหาเอง`
  บรรทัด 2: `ดีลใหม่ทุกวัน • รวมไว้กว่า 500 ดีล` (เช็คตัวเลข)
  บรรทัด 3: `ลิงก์พันธมิตร มีค่าคอมมิชชั่น #ad` (จำเป็น)
  บรรทัด 4 (หลัง 26 ต.ค.): `ดูดีลวันนี้ 👉 paiyaadeals.com` + ใส่ URL ในช่อง **website/Links** ของแอป (ไม่ใช่ในข้อความ — Graph API แก้โปรไฟล์ไม่ได้ ต้องทำในแอป)
- **TikTok @sup.tw** (บัญชี private จนกว่า audit ผ่าน · ห้ามเสนอเปิดบัญชีใหม่): ชื่อ `ป้ายยาดีลเด็ด | Paiyaa deal` · bio 80 ตัว: `คัดดีล Shopee/Lazada ลดจริงทุกวัน • ดีลเต็มที่ paiyaadeals.com • #ad ลิงก์พันธมิตร`
- **Facebook เพจ ป้ายยาดีลเด็ด** (facebook.com/paiyaa.deals): ช่อง Intro = บรรทัด 1 + 2 · ปุ่ม CTA ของเพจ = "เยี่ยมชมเว็บไซต์" → paiyaadeals.com · ส่วน "เกี่ยวกับ" ใส่เปิดเผยพันธมิตร
- **Threads @paiyaa_deals**: bio สั้น = บรรทัด 1 + CTA เว็บ
- **รูปโปรไฟล์**: ตอนนี้เป็นโลโก้ตัวอักษร "ป" บน #C63F1E (`/root/deal-video/tiktok/app-icon-1024.png`) — คลิปแนะนำรูปคนมีบุคลิก แต่ช่องเราไม่มีพิธีกร → ใช้โลโก้เดิมได้ ขอให้ **เหมือนกันทุกแพลตฟอร์ม** และอ่านออกตอนเล็ก (ฟอนต์ที่ไม่มี "ป" ทำให้ TikTok แสดงคล้าย "U" — เปลี่ยนหลัง audit ผ่าน)

## กติกาที่ต้องเช็คก่อนเสนอ bio
- ตัวเลขใน "หลักฐาน" ต้องจริงและตรวจได้ (นับจาก Notion สถานะ โพสต์แล้ว / จำนวนรอบต่อวัน) — ห้ามอ้างยอดขาย/ผู้ติดตามที่ไม่มี
- ห้ามคำว่า "ถูกสุด" "ของแท้ 100%" "ใช้แล้วดี" (กฎเดียวกับบทพากย์ `SCRIPT_BANNED`)
- การแก้โปรไฟล์/ชื่อ/username ทุกแพลตฟอร์มต้องให้ user ทำในแอปเอง (Meta เคยแฟล็ก automation · FB username ต้องยืนยันรหัสผ่าน)
- เปลี่ยน bio แล้วจดวันที่ลง CLAUDE.md หัวข้อแพลตฟอร์มนั้น
