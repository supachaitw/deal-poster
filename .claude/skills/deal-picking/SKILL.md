# หลักเลือกสินค้า 5 ประเภท (ขายดีใน TikTok มือใหม่ก็เริ่มได้)

ที่มา: อินโฟกราฟิก "5 ประเภทสินค้าขายดีใน TikTok" (ครูชิน รายได้แห่งการขาย) user ส่งให้ 3 ต.ค. 69 สั่ง "เพิ่มลง skill ไว้ด้วย"

| ประเภท | ชื่อ | ทำไมถึงขาย | ตัวอย่างในภาพ | บทบาทในช่องเรา |
|---|---|---|---|---|
| **A** | สินค้าขายดี (ตัวเริ่มต้นยอด) | คนใช้เยอะ · ขายง่าย กำไรดี · รีวิวเยอะ · ลูกค้าประทับใจ | แก้วเก็บความเย็น, กระเป๋าแฟชั่น, ชุดนอน, ของใช้ยอดฮิต | **ฐานยอด** — ควรเป็นส่วนใหญ่ของคิว ทุกรอบควรมี |
| **B** | สินค้าใหม่ (กระแส ลูกค้าอยากลอง) | ดึงดูดความสนใจ · สร้างกระแสในช่อง · เพิ่มโอกาสขาย · ยอดดูไลฟ์พุ่ง | ของมาใหม่, ของน่ารักตามกระแส, สินค้าเทรนด์ | **ตัวเรียกวิว** — ใช้เป็นดีลแรกของรอบ (ตัวที่ได้ Veo/TikTok/FB Reel) |
| **C** | สินค้าสิ้นเปลือง (ใช้บ่อย ต้องซื้อซ้ำ) | ลูกค้ากลับมาซื้อซ้ำ · รายได้ต่อเนื่อง · หมุนเงินไว | สบู่, สกินแคร์, ของใช้ประจำวัน | **ยอดสม่ำเสมอ** — เหมาะกับหมวด บ้าน/อาหาร/กาแฟ/ความงาม ที่คิวมีอยู่แล้ว |
| **D** | สินค้าคอมสูง (เพิ่มกำไรให้ช่อง) | กำไรต่อชิ้นสูง · ไม่ต้องแข่งราคา · สร้างรายได้หลัก | กระเป๋าแบรนด์, น้ำหอม, เครื่องประดับ, สินค้าพรีเมียม | **ตัวทำเงิน** — ดู `คอม%` ใน Notion (property มีแล้วแต่ยังไม่ค่อยกรอก) อย่าให้คิวมีแต่ของถูกคอมต่ำ |
| **E** | สินค้าประจำช่อง (เอกลักษณ์ของช่อง) | สร้างตัวตนให้ช่อง · แฟนคลับรักและซัพพอร์ต | สินค้าที่คัดสรรโดยเรา, สินค้าเอนท์ | **ตัวตน "ป้ายยาดีลเด็ด"** — ดีลที่ลดแรงจริง/ของใช้บ้านคุ้ม ๆ ที่ช่องเราชอบป้ายยาเป็นประจำ |

ข้อสรุปจากภาพ: **เลือกให้เหมาะกับสไตล์ของเรา แล้วเริ่มทำคอนเทนต์ได้เลย** — ไม่ต้องครบทุกประเภทในวันเดียว แต่คิวรวมควรมีส่วนผสม

## วิธีใช้กับระบบ Deal Poster
1. **ตอนคัด/อนุมัติดีล** (หน้า dealposter.html หรือ Notion สถานะ ใหม่/รอตรวจ): ติดป้ายในใจว่าเป็น A–E · ดีลที่ไม่เข้าสักประเภท (ของเฉพาะทางมาก ไม่มีรีวิว ราคาไม่ลด คอมต่ำ) = ตัวเลือกให้ทิ้งก่อน
2. **จัดลำดับในรอบ** (ดีลแรกของรอบได้ Veo/keyframes + TikTok + FB Reel): ควรเป็น **B หรือ A ที่ลดแรง (≥ 30%)** · ข้อจำกัดปัจจุบัน: `Query Approved Deals` ไม่มี sort → Notion คืนเรียง last_edited **เก่าก่อน** (FIFO) และ `Split Approved` ตัด 6 ตัวแรก จึงบังคับลำดับไม่ได้จาก Notion ตรง ๆ · ทางที่ทำได้: (ก) พักดีลอื่นเป็น "รอตรวจ" ชั่วคราวให้ดีลที่ต้องการขึ้นก่อน (ข) เสนอ user เพิ่ม property `เด่น` (checkbox) แล้วแก้ `Split Approved` ให้ดีลที่ติ๊กขึ้นเป็นลำดับแรก (ยังไม่ทำ ต้องให้ user เคาะ)
3. **ส่วนผสมต่อวัน (เป้าหมายคร่าว ๆ 42 ดีล/วัน)**: A 40% · C 25% · B 15% · D 10% · E 10% — ถ้าคิววันไหนเป็น C ล้วน (เช่น 28 ก.ย. อาหาร 21 ดีล) ให้บอก user ว่าขาด A/B/D
4. **เขียน hook/บท** (`script_style.txt` / prompt Sonnet): A = ชูว่าคนใช้เยอะ/รีวิวเยอะ (ห้ามอ้างว่าเราใช้แล้วดี) · B = ความใหม่/กระแส · C = "ของที่ต้องซื้ออยู่แล้ว ซื้อตอนลดดีกว่า" · D = คุณค่า/พรีเมียมในราคาที่ลด · E = น้ำเสียง "ป้ายยาประจำช่อง"
5. **หาสินค้าใหม่มาลง** เมื่อ user ถาม "ควรหาอะไรมาลง": ไล่ตามตาราง — เริ่ม A (ของฮิตที่มีรีวิวเยอะในหมวดที่ช่องถนัด: บ้าน/gadget/อาหาร) → เสริม C ที่ซื้อซ้ำ → แทรก B ตามเทรนด์ TikTok เดือนนั้น (ดู skill `tiktok-analyze` และ `script_style.txt`) → เติม D จากหมวดความงาม/แฟชั่นที่คอมสูง

## เตือนความจำ
- ข้อมูลประเภทยังไม่มีใน Notion — ถ้า user อยากให้ระบบรู้เอง ต้องเพิ่ม property `ประเภท` (select A–E) + ให้ `Claude Parse`/`Claude Write Caption` เติม (แก้ 3 intake + Caption Writer) — เสนอก่อนทำ
- กฎเดิมยังอยู่: ห้ามสร้างแถวทดสอบสถานะ "ใหม่" · ห้ามเปลี่ยนสถานะกลับเป็น "อนุมัติแล้ว" · ลิงก์ Shopee ต้องเป็น affiliate

# ส่วน 2 — ตรวจสินค้ารายชิ้นก่อนสร้างลิงก์ (5 ขั้น) + คิดมุมคอนเทนต์ก่อน

ที่มา: โพสต์ "มือใหม่ Shopee Affiliate เลือกสินค้ายังไงดี" (ตัวอย่างชั้นวางเครื่องปรุงในครัว) user ส่งให้ 16 ต.ค. 69 สั่ง "วิเคราะห์ ถ้าดีเก็บเข้า skill"
ผลวิเคราะห์: เป็นหลักพื้นฐานที่ถูกต้องและ**เติมช่องว่างของส่วน 1** — ส่วน 1 บอกว่าควรหาสินค้า*ประเภท*ไหน ส่วนนี้บอกว่าพอเจอสินค้า*ชิ้นหนึ่ง*แล้วต้องตรวจอะไรก่อนลง และต้องคิดมุมเล่าก่อนสร้างลิงก์ · ข้อจำกัด: เขียนสำหรับคนทำคอนเทนต์มือ 1 ชิ้น/ครั้ง (ของเราโพสต์ 42 ดีล/วันอัตโนมัติ) จึงใช้เป็น**เช็กลิสต์ตอน user เลือกของในแอป** และกติกาเขียน hook ไม่ใช่ขั้นตอนในระบบ · ตัวเลข "14 ออเดอร์ = 210 บาท" เป็นแค่ตัวอย่างคูณ ไม่ใช่สถิติ · โพสต์ต้นทางเป็นคอนเทนต์ affiliate เอง (แปะลิงก์ชั้นวางของตัวเอง) = ตัวอย่างจริงของการใช้หลักนี้

## เช็กลิสต์ 5 ขั้น (ทำในแอป Shopee ก่อนกด "แชร์และรับค่าคอม")

| ขั้น | ทำอะไร | ของเราเชื่อมกับอะไร |
|---|---|---|
| 1 ค้นหาในโปรแกรม affiliate | เข้าหน้า Shopee Affiliate ในแอป พิมพ์ชื่อหมวดสินค้า (ไม่ใช่ค้นหน้าร้านปกติ) — รายการที่ขึ้นคือของที่**เข้าร่วมโปรแกรมแน่** และเห็น % คอมเลย | ลิงก์ที่ได้จากหน้านี้ขึ้นต้น `s.shopee.co.th` เสมอ → ผ่านด่าน #intake (ลิงก์ Shopee ธรรมดาถูกลบ ดู CLAUDE.md 16 ต.ค. 69) |
| 2 อ่านรีวิวผู้ซื้อจริง | ดู**รูปรีวิว** (ของจริงต่างจากรูปร้านไหม) · ขนาด · วัสดุ · ความแข็งแรง/ใช้แล้วพังไหม | รูปรีวิวบอกว่าคลิป Veo/storyboard ควรสาธิตอะไร · ถ้ารีวิวบ่นเรื่องเดียวกันหลายคน = ไม่ลง (ป้ายยาแล้วคนผิดหวัง เสียความเชื่อถือช่อง) |
| 3 เทียบหลายร้าน | ไม่เอาถูกสุดอย่างเดียว: คะแนนร้าน · ค่าส่ง · รายละเอียดสินค้าครบไหม · จำนวนขายแล้ว | ลิงก์เดียวกันซ้ำใน Notion ถูก dedupe บนเว็บอยู่แล้ว แต่ของชิ้นเดียวกันคนละร้านไม่ถูกจับ → ถ้าลงซ้ำให้เลือกร้านที่ดีกว่าแล้วซ่อนอีกแถว (`ซ่อนเว็บ`) |
| 4 เช็กค่าคอม | สินค้าเข้าร่วมโปรแกรมไหม · คอมกี่ % / กี่บาทต่อออเดอร์ · เป็น **Extra Commission** (แคมเปญคอมเพิ่มช่วงหนึ่ง) ไหม — แต่ละชิ้นไม่เท่ากัน | กรอก `คอม%` ใน Notion ตอนส่งดีล (property มีแล้ว แทบไม่มีใครกรอก) · ประเภท D ของส่วน 1 ใช้ค่านี้ตัดสิน · คิดเป็นเงินจริง: คอม/ออเดอร์ × จำนวนออเดอร์ ไม่ใช่จำนวนโพสต์ — คลิกจริงบนเว็บเรายังหลักหน่วย/สัปดาห์ (clicks.html) ดังนั้น "ลงเยอะ" ไม่เท่ากับ "ได้เงิน" |
| 5 คิดมุมคอนเทนต์ก่อนสร้างลิงก์ | ตั้งประโยคเล่าให้ได้ก่อน แล้วค่อยกดสร้างลิงก์ — ถ้าคิดมุมไม่ออกแปลว่าสินค้ายังอธิบายจุดเด่นไม่ได้ ไม่ควรลง | ใช้เป็น 3 แม่แบบ hook ด้านล่าง · ใส่ไว้ในข้อความแชร์ที่วางใน #intake ได้เลย (ข้อความทั้งก้อนไป `Claude Parse` → `คำบรรยาย`) |

## 3 มุมเล่าจากโพสต์ (แม่แบบ hook — ใช้กับ `script_style.txt` / prompt Sonnet ได้)

| มุม | โครง | ตัวอย่างในโพสต์ | เงื่อนไขของระบบเรา |
|---|---|---|---|
| ปัญหา → วิธีจัดการ | "<อาการที่คนเจอ> ลองทำแบบนี้" | "ครัวรกเพราะเครื่องปรุงเยอะ ลองจัดระเบียบแบบนี้" | ตรงกับ hook แบบปัญหาที่ Sonnet เขียนอยู่แล้ว (เช่น 'มือถือแบตหมดกลางทาง…') — ใช้ได้เลย |
| งบน้อยก็ทำได้ | "งบไม่เยอะ ก็ <ผลลัพธ์> ได้" | "งบไม่เยอะ ก็ทำให้ครัวดูเป็นระเบียบขึ้นได้" | เข้ากับดีลราคาถูก/ลดแรง · ห้ามพูดตัวเลขใน hook (ด่าน `script_ok`) ตัวเลขอยู่ท่อนราคาเท่านั้น |
| เช็กก่อนซื้อ | "ก่อนซื้อ <สินค้า> ต้องเช็ก <N> อย่างนี้" | "ก่อนซื้อชั้นวางเครื่องปรุง ต้องเช็ก 3 อย่างนี้" | เขียนตัวเลขเป็นคำ ("สามอย่าง") เพราะ hook ห้ามมีตัวเลข · ตัวเช็กต้องมาจากชื่อ/คำบรรยายจริง ห้ามแต่งสเปก · เป็น open loop ในตัว (คนดูจนจบเพื่อรู้ครบ) เข้ากับโครง Howard |

## หลักที่เอามาใช้กับช่องเรา
- **สินค้าที่ลงต้อง "อธิบายจุดเด่นได้ + มีข้อมูลให้ตรวจ"** ไม่ใช่แพงสุดหรือคอมสูงสุด — ดีลที่ชื่อสินค้าบอกอะไรไม่ได้และไม่มีรีวิว ให้ทิ้งก่อน (สอดคล้องข้อ 1 ของส่วน 1)
- **ของดี 1 ชิ้น → หลายคอนเทนต์** โพสต์ต้นทางย้ำว่ามือใหม่ให้เลือก 1 ชิ้นแล้วแตกเป็นหลายโพสต์คนละมุม · ของเรา: ดีลที่มีคลิกจริง (ดู `gen.py stats`/clicks.html) ค่อยเอามา render ซ้ำด้วย hook คนละมุม (`script_log` LRU ให้สำนวนใหม่เองอยู่แล้ว · ส่งผ่าน `/clip` หรือ Reply ใน #clips) แทนที่จะหาของใหม่เรื่อย ๆ — **ยังไม่มีข้อมูลพอ** (คลิกจริง 7 ครั้งใน 13 ต.ค.) ให้ดูเมื่อมีคลิกสะสม
- **ค่าคอมมาจากออเดอร์ ไม่ใช่โพสต์** — เวลา user ถามว่า "ทำไมยังไม่ได้เงิน" ให้ตอบด้วยสมการนี้ + จำนวนคลิกจริง ไม่ใช่จำนวนโพสต์
- สิ่งที่โพสต์ไม่ได้พูดแต่ของเราต้องเพิ่ม: ลิงก์ต้องเป็น affiliate (`s.shopee.co.th`) · ราคาเต็ม Shopee ไม่มีในข้อความแชร์ (ดู CLAUDE.md 13 ต.ค.) · เปิดเผย #ad
